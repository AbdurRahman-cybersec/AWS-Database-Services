📖 Key Concepts

Three mental models that show up all over the CCP exam.

🏪 OLTP vs 📊 OLAP

OLTPOLAP
Online Transaction ProcessingOnline Analytical Processing
Day-to-day app operationsReporting & business intelligence
Placing orders, logging inSales trends from years of data
→ RDS, Aurora, DynamoDB→ Redshift
Many small, fast transactionsFew large, complex queries

🗄️ SQL vs 🔑 NoSQL

SQLNoSQL
Structured tables & rowsFlexible schema
Fixed schema, relationshipsKey-value, document, graph
ACID transactionsMassive horizontal scale
→ RDS, Aurora→ DynamoDB, DocumentDB
MySQL, PostgreSQL, SQL ServerJSON, key-value, MongoDB-like

☁️ Managed DB vs 🖥️ DB on EC2

Managed (RDS, DynamoDB…)Self-managed on EC2
AWS handles patching, backups, HAYou install & maintain everything
Automatic failover & scalingYou configure failover manually
Pay for the servicePay for EC2 + your time
✅ CCP answer: prefer managedOnly if you need full control
